POST/api/observe/logs/disable/{hostname}

execute tier

Disable log forwarding for all sources on a hostname by transitioning each to NotConfigured.

Disable log forwarding for all sources on a hostname by transitioning each to NotConfigured.

Requires a database. Disables every still-active source for the hostname in one atomic, advisory-locked step (repos::log_forwarders::disable_all_for_hostname) so it cannot race a concurrent onboard or be left partially applied. The response lists the sources that were actually transitioned.

Example request

curl -s -X POST -H "Authorization: Bearer <token>" https://<your-host>/api/observe/logs/disable/{hostname}

Request body not extracted — see handler logs_disable.

GET/api/observe/monitoring-review-queue

read tier

GET /api/observe/monitoring-review-queue — the LIVE monitoring review queue (#29).

GET /api/observe/monitoring-review-queue — the LIVE monitoring review queue (#29). The monitoring_review_queue table (migration 031) was seeded but never read by the API — only the static contract endpoint existed. This turns it into a real read surface, mirroring how shift_queue is exposed. Request-tier read, site-scoped (#2): a scoped principal sees only its own site's items; an environment-scoped principal sees none (this queue is site-only). Ordered by SLA deadline (most urgent first). Empty + durable:false when no DB is configured.

Query parameters

NameTypeRequiredDescription
limiti64optional
offseti64optional

Response: Returns a paginated JSON object with total/limit/offset keys.
