Me API

Self-service endpoints for the signed-in user's own scope preferences; writes are keyed on the verified session identity.

2 routes

GET/api/me/preferences

read tier

GET /api/me/preferences — the CURRENT user's scope preferences (#59).

GET /api/me/preferences — the CURRENT user's scope preferences (#59). Keyed on the verified session.user_id; returns nulls when none are set. Self-service (any authenticated user); empty + durable:false with no DB.

Example request

curl -s -H "Authorization: Bearer <token>" https://<your-host>/api/me/preferences

PUT/api/me/preferences

read tier

PUT /api/me/preferences — set the CURRENT user's scope preferences (#59).

PUT /api/me/preferences — set the CURRENT user's scope preferences (#59). Full replace (absent/null/empty clears a field). Keyed on the verified session.user_id — a client cannot write another user's preferences. Self-service; 503 with no DB.

Request body

Structure: UserPreferencesRequest

preferred_siteStringoptional

Example request

curl -s -X PUT \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"preferred_site": "<string>", "preferred_environment": "<string>"}' \
  https://<your-host>/api/me/preferences
