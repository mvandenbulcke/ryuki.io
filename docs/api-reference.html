Documentation / API Reference

Ryuki API Endpoints

The control plane serves 747 routes across 37 areas. Most routes require an authenticated session or an API bearer token; a small set is deliberately unauthenticated, such as health probes, agent registration, and the control-plane public key. Authorization is tiered per route (admin, approve, execute, request, audit) and reads are narrowed by the caller's site and environment scopes; RBAC & Scoping documents the enforcement semantics.

Generated by ryuki-validator generate-endpoints-doc from the route registrations in:

  • sources/ryuki-api/src/contracts.rs
  • sources/ryuki-api/src/main.rs
  • sources/ryuki-api/src/boundary.rs

Regenerate with cargo run --manifest-path scripts/validator-rs/Cargo.toml -- generate-endpoints-doc. Do not edit by hand.
