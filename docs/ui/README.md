# Ryuki Portal UI Documentation

This directory holds the static UI design artifacts for the Ryuki portal: the
design system, the portal information architecture, the accessibility checklist,
and the Batch 2 mockup wireframes. These documents are referenced by the
`design-system`, `portal-information-architecture`, and `ui-mockup-acceptance`
slices in the static validator.

All mockups are static wireframes only. They describe layout and behavior for a
future implementation and carry no live execution, no browser provider calls, and
no external asset fetches.

## Scope

The current scope is the Batch 2 product shell and the workspaces that hang off
it. The Batch 2 product shell defines the shared chrome — the scope band, the
navigation rail, and the content region — that every workspace mockup inherits.
